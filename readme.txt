英文打字練習小工具
==================

一、製作這個小工具的 Prompt
--------------------------

製作一個英文打字練習小工具，

用 python 撰寫，寫在一個 py 裡面，

py 打開有一個 UI，

UI 分為上方的題目文字欄，和下方的輸入文字欄，

題目文字欄可以讓使用者可以貼上英文段落，

輸入文字欄可以讓使用者打入英文段落，

下方有一排按鈕，從左到右是，清空題目、清空輸入，

小工具的功能是檢查題目文字欄和輸入文字欄是否一致，

當使用開始在輸入文字欄打入英文字、符號、空格時，會立即開始檢查，

比如題目文字欄貼上了一個英文段落：
When I think about my work life, there are definitely moments I’d do differently

然後當使用者在輸入文字欄打入：When I think，這時候因為有匹配到一樣的段落，這時候 When I think 會標上綠色底色，那如果使用者輸入 When U think，那 U 這個英文字就會標成粉紅色。

補充確認：
1. 綠色／粉紅色標在下方輸入欄。
2. 採「逐字繼續比」，可隨時用 Backspace 修正。
3. 使用 tkinter（標準庫）、按鈕文字繁中，先不做計時／WPM／正確率。


二、操作說明
----------

1. 啟用虛擬環境（專案資料夾 env）後啟動程式：

   .\env\Scripts\Activate.ps1
   python typing_practice.py

   或不啟用虛擬環境，直接執行：

   .\env\Scripts\python.exe typing_practice.py

2. 在上方「題目」欄貼上或輸入要練習的英文段落。

3. 在下方「輸入」欄依題目打字。
   - 與題目相同的字元：綠色底色
   - 與題目不同的字元：粉紅色底色
   - 輸入比題目還長的字元：視為錯誤（粉底）
   - 可隨時用 Backspace 或直接修改中間內容，標色會即時更新

4. 按鈕：
   - 清空題目：清除上方題目欄內容
   - 清空輸入：清除下方輸入欄內容

5. 關閉視窗即可結束程式。
